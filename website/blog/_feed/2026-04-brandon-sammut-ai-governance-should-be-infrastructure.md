# "AI governance should be infrastructure, not a job" — Brandon Sammut, Zapier

120 reactions, 24 comments at capture. Six months old; too stale to engage.

## Summary (paraphrase; full text not captured)

A product announcement in argument form. When governance depends on a person, that person becomes the bottleneck; the fix is safeguards built into the workflow. Zapier shipped six things: action restrictions at the endpoint level, managed app connections with domain control, bring-your-own-model via AWS Bedrock, a queryable audit trail, MCP governance for Zapier Agents, and Workspaces.

Quote as reported: "When governance is infrastructure, teams build within always-on guardrails within the flow of work itself. No tickets. No single person carrying the weight."

## Relevance to Downstream

A non-Dashbud example for post 3: a horizontal automation vendor building the gate (scoped actions, audit trail, your own model) as product. It's an announcement, not an argument, so cite it as an example of the pattern, not as support for the thesis. Note the tension with the skipped step: "no single person carrying the weight" is true of enforcement, but someone still has to decide the policy. That's the line to draw if it's used.
