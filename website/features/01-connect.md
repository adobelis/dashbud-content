## Short
Upload spreadsheets, connect directly to databases, or sync from cloud sources like Google Sheets. No data warehouse required.

## Long
Dashbud's smart data loading handles formats automatically — type casting, date parsing, currency formatting — so your data is clean and queryable from the start. Every import is versioned and can be rolled back.

No data lake. No ETL pipeline. No migration project. Just connect what you have and start working.

**Works with:** CSV and Excel file uploads, Google Sheets, PostgreSQL, SQL Server, MySQL, Oracle, Redshift, and more.
