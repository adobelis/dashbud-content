 `js-yaml` is a JavaScript library that parses YAML files and converts them to JavaScript objects (and vice versa).

**What it does:**
```yaml
# YAML file
title: "Hello"
items:
  - one
  - two
```

Gets converted to:
```javascript
{
  title: "Hello",
  items: ["one", "two"]
}
```

**Why we need it:**
Astro doesn't have built-in YAML support, so we need this library to read your `how-it-works.yaml` file and turn it into a JavaScript object we can work with.

**Installation:**
```bash
npm install js-yaml
npm install -D @types/js-yaml  # if using TypeScript
```

**Alternative approach:**
If you don't want to add another dependency, we could:
1. Use JSON instead of YAML (but less readable)
2. Keep the content as JavaScript objects in the Astro file (but less clean)
3. Use Astro Content Collections (but more complex setup)

YAML + js-yaml is the simplest path to clean, editable content that will easily port to Sanity later. But let me know if you'd prefer a different approach!
