 In VS Code, right-click on the SVG file in the file explorer or in the editor tab and select **"Reopen Editor With..."** then choose **"Text Editor"** (or press `Ctrl+Shift+P` / `Cmd+Shift+P` and type "Reopen Editor With").

By default, VS Code opens SVGs in a preview mode, but you need the text editor to actually edit the code.

Alternatively, you can change the default behavior:
1. Go to Settings (`Ctrl+,` / `Cmd+,`)
2. Search for "svg"
3. Look for `"workbench.editorAssociations"` 
4. Add or modify to make `*.svg` open with the text editor by default
