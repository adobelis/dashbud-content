### **Visx (VX): Low-Level Primitives**
```jsx
// Visx: Build from scratch with primitives
import { Group } from '@visx/group';
import { Bar } from '@visx/shape';
import { scaleBand, scaleLinear } from '@visx/scale';
import { AxisBottom, AxisLeft } from '@visx/axis';

function MyChart({ data, width, height }) {
  const xScale = scaleBand({
    domain: data.map(d => d.label),
    range: [0, width],
    padding: 0.4,
  });
  
  const yScale = scaleLinear({
    domain: [0, Math.max(...data.map(d => d.value))],
    range: [height, 0],
  });
  
  return (
    <svg width={width} height={height}>
      <Group>
        {data.map(d => (
          <Bar
            key={d.label}
            x={xScale(d.label)}
            y={yScale(d.value)}
            width={xScale.bandwidth()}
            height={height - yScale(d.value)}
            fill="blue"
          />
        ))}
        <AxisBottom scale={xScale} top={height} />
        <AxisLeft scale={yScale} />
      </Group>
    </svg>
  );
}
```

**Ease Rating: ⭐⭐ (2/5) - Hard**
- ❌ Build everything from scratch
- ❌ You manage scales, layouts, positioning
- ❌ No default styling or behaviors
- ✅ Complete control over every pixel
- ✅ Tiny bundle (only what you need)
- ✅ React-native patterns (if you know D3)

## TL;DR - Quick Wins to Make ECharts Look Amazing:

### **🎨 Instant Visual Upgrades:**
1. **Use a built-in theme** - `theme="dark"` or `theme="macarons"` (way better than default!)
2. **Add gradients** - Makes any chart look modern instantly
3. **Use shadows** - `shadowBlur: 10` for depth
4. **Smooth lines** - `smooth: true` for elegant curves

### **⚠️ Critical Mistakes to Avoid:**
1. **Don't create option inline** → Use `useMemo` or you'll get terrible performance/flicker
2. **Tree-shake your imports** → Import only specific modules to cut bundle from 800KB to 200KB
3. **Charts won't resize** → Use `width: '100%'` and `autoResize={true}`
4. **Animations on every update** → Set `notMerge={false}` to prevent re-animation

### **🚀 Best React Pattern:**
```jsx
import { useMemo } from 'react';
import ReactECharts from 'echarts-for-react';

function MyChart({ data }) {
  const option = useMemo(() => ({
    color: ['#5470c6', '#91cc75', '#fac858'],  // Better colors
    grid: { left: '3%', right: '4%', containLabel: true },  // More space
    series: [{
      type: 'line',
      smooth: true,  // Smooth lines
      data: data.values,
      areaStyle: {  // Gradient fill
        color: {
          type: 'linear',
          colorStops: [
            { offset: 0, color: 'rgba(88, 80, 236, 0.4)' },
            { offset: 1, color: 'rgba(88, 80, 236, 0.0)' }
          ]
        }
      }
    }]
  }), [data]);

  return <ReactECharts option={option} theme="dark" />;
}
```
